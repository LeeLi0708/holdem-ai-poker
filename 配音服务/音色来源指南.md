# 去哪里找免费的音色

**一句话**：CosyVoice 靠「一段 6~10 秒的参考音频」克隆嗓子。
所以真正要找的不是「音色包」，而是**干净的、你有权使用的人声片段**。

好消息是：**最省事的那条路完全不花钱、不下载、也不涉及任何授权** —— 自己录。

---

## 一、四条路，按省事程度排

| 路径 | 花费 | 要下多少 | 音色数 | 授权风险 | 适合 |
|---|---|---|---|---|---|
| **① 自己录** | 0 | **0** | 想要几个有几个 | **无**（自己的声音） | 想彻底私有化 |

## 二、① 自己录（最推荐）

**零成本、零下载、零法律风险，而且你今天就能做完。**

### 怎么录

| 项 | 要求 |
|---|---|
| 时长 | **6~10 秒**（一句话，别太长） |
| 设备 | 手机自带录音机就够；离嘴 15~20 cm，别喷麦 |
| 环境 | **安静房间**，关空调/风扇/窗，别用带混响的卫生间 |
| 内容 | 一句自然的话，**音节覆盖广一点**（别只说「你好」） |
| 格式 | 录完转成 WAV（多数手机给 m4a，用格式工厂/ffmpeg 转一下），采样率 ≥16000 Hz |

录音参考句（挑一句念，或自己写）：
> 「今天的天气还算不错，我们慢慢来，不用着急。」

### ⚠️ 一个人怎么录出 7 个不同嗓子

这是最实际的问题。**答案是：不用换人，用「音高 + 语速 + 口音 + 语气」四个轴去拉。**

| 轴 | 怎么调 | 效果 |
|---|---|---|
| **音高** | 刻意抬高 / 压低嗓子 | 最有效。差 4~6 个半音，一听就是两个人 |
| **语速** | 快 1.3 倍 / 慢 0.8 倍 | 实测**语速差 20% 以上**，人耳就能分辨 |
| **口音** | 普通话 / 东北 / 四川 / 陕西 / 台湾腔 | 差异最明显，但要有才行 |
| **语气** | 冷硬 / 热情 / 慵懒 / 有攻击性 | 配合角色的性格设定 |
| **距离** | 近讲（低厚）/ 远讲（清亮） | 音色质感会变 |

**对着这 7 个角色录一遍试试**：

| 角色 | 怎么念 | 参考 |
|---|---|---|
| 李姨 🀄 | 压低、放慢、不带情绪 | 像在称量你 |
| 麦琪 🔥 | 抬高、加快、有冲劲 | 像要掀桌 |
| 艾米 🧮 | 中音、平稳、念数字的口气 | 不带情绪 |
| 杰西 🃏 | 中高、尾音上挑、有点飘 | 让人分不清真假 |
| 王姨 🧶 | 中低、慢、带点方言 | 像在唠叨 |
| 莉莉 🍬 | 高、软、慢 | 觉得热闹 |
| 虎姐 🐯 | 低、有力、偏快 | 在压你 |

**如果实在不想录 7 段**：录 2~3 段，其余的先用 CosyVoice 生成的顶着
（见第三节），之后再慢慢换。

> **实测参考**：用同一段参考音频 + 不同语速（±18%）合成，人耳就能分辨出是「两个人」。
> 所以 7 个角色不必凑 7 个真人 —— 音高和语速拉够，数量不是问题。

### 录完怎么用

```
1. 把文件放到  配音服务\音色参考\  目录，命名成  <角色key>.wav
       liyi.wav / maiqi.wav / aimi.wav / jiexi.wav / wangyi.wav / lili.wav / hujie.wav

2. 同时建一个同名 .txt 写上你念的内容（必须一致！）
       liyi.txt  →  今天的天气还算不错，我们慢慢来，不用着急。

3. 重新注册音色：
       C:\ProgramData\miniconda3\envs\cosyvoice\python.exe 配音服务\准备音色.py

4. 重启配音服务，点面板里的 ▶ 试听
```

> ⚠️ **那个 `.txt` 不能省。** CosyVoice 注册音色时要拿它跟音频做对齐，
> 文本对不上会明显拉低克隆质量。脚本会优先读 `.txt`，没有才回落到内置句。

## 四、③ AISHELL-3 数据集（最正经的「免费真人音色」）

**85 小时、218 个说话人、88035 条语音，明确标注了性别/年龄/口音。**

| 项 | 值 |
|---|---|
| 时长 | 85 小时 |
| 说话人 | 218 人（有性别/年龄/口音标注） |
| 采样率 | 44.1 kHz 单声道（高保真） |
| 体积 | **19 GB**（单个 tgz） |
| 下载 | OpenSLR：https://openslr.org/93/ （国内可达，实测 200 OK） |
| 备用 | ModelScope：`datasets/speech_tts/AISHELL-3` |
| 许可 | **⚠️ 有矛盾，见第五节** |

### ⚡ 更省事的做法：根本不用下那 19GB（实测）

**先说结论**：`19 GB` 是「整个包」的体积，但你只需要 7 段 3~10 秒的音频 —— **总共几 MB**。
前提是能按需取。实测三条通道：

| 通道 | 速度 | 下完 19GB 要 |
|---|---|---|
| OpenSLR 主站 | 0.2 MB/s | **约 24 小时** |
| OpenSLR EU / CN 镜像 | 0.12 MB/s | 更慢（CN 镜像实测几乎不动） |
| **ModelScope 单文件接口** | **3 MB/s** | 而且**只取你要的那几个文件** |

所以正确姿势是走 ModelScope，并且**只下需要的几条**。三个关键发现让它成立：

1. **`spk-info.txt`（218 人的性别/年龄/口音）在压缩包最前面** —— 前 5 MB 就能拿到全部元数据
2. **目录顺序是 `test/` 在前、`train/` 在后**，而 `test/` 集自己就有 **214 个说话人（172 个女声）**，且**全部带转写**
3. ModelScope 的文件树接口能单独查每个说话人的文件清单和字节数 —— 44.1 kHz / 16 bit / 单声道 = **每秒 88200 字节**，按文件大小就能算出时长，不用下载

一条命令搞定（脚本已写好）：

```
# 看有哪些女声可选（按年龄段分组，标出最长音频多少秒）
...\envs\cosyvoice\python.exe 配音服务\从ModelScope挑音色.py --list

# 按内置方案取一整套（7 个角色的年龄段和设定对齐）
...\envs\cosyvoice\python.exe 配音服务\从ModelScope挑音色.py --auto

# 只换其中两个
...\envs\cosyvoice\python.exe 配音服务\从ModelScope挑音色.py --pick liyi=SSB0354,maiqi=SSB0702
```

⚠️ 取完**必须**跑 `准备音色.py --rereg` 重新注册，否则音色表里还是旧的（见第八节的坑）。

**⚠ 一个实测细节**：`test/` 集的音频**普遍只有 1.5 秒**，太短学不像。
所以脚本专门挑 **3~10 秒**的条。下面这 7 个说话人是实测挑出来的（单条就有 3~6 秒）：

| 角色 | 说话人 | 年龄段 | 口音 | 参考音频 |
|---|---|---|---|---|
| 李姨 🀄 | SSB0354 | D (>41) | north | 5.7s |
| 王姨 🧶 | SSB0737 | D (>41) | north | 2.8s ← 偏短 |
| 麦琪 🔥 | SSB0702 | B (14~25) | south | 6.2s |
| 莉莉 🍬 | SSB0693 | B (14~25) | south | 5.7s |
| 艾米 🧮 | SSB0671 | C (26~40) | north | 12.1s |
| 杰西 🃏 | SSB0341 | C (26~40) | north | 5.0s |

> D 段（>41 岁）的女声**总共只有 7 人**，所以李姨和王姨的可选余地最小 —— 想换只有这几个。

### 下载后怎么用（整包路线）

**关键：88035 条里挑 7 条，手动不可能。用我写的脚本。**

```bash
# 先看看有哪些女声可用（不写文件）
C:\ProgramData\miniconda3\envs\cosyvoice\python.exe 配音服务\从数据集挑音色.py ^
    --data D:\data_aishell3 --list

# 挑 7 个不同说话人，自动写成参考音频
C:\ProgramData\miniconda3\envs\cosyvoice\python.exe 配音服务\从数据集挑音色.py ^
    --data D:\data_aishell3 -n 7
```

脚本会自动做这些事：
- 读 `spk-info.txt` 拿性别/年龄 → **默认只挑女声**
- 按 **6~10 秒**筛（太短不像、太长没必要）
- **每个说话人只取一条**（保证 7 个嗓子不重复）
- 转成 **16kHz 单声道**（CosyVoice 的硬要求）
- **去掉首尾静音**（否则克隆出来会「慢半拍」）
- 连**转写文本**一起写出来（`.txt`，注册音色必须用它）

常用参数：

```
--min 5 --max 9        改时长范围
--age 25-35            只要这个年龄段
--gender any           不限性别
--spks SSB0005,SSB0011 只用指定说话人（挑好后想复现同一批）
--need-text            只挑有转写的（推荐开）
--force                覆盖已有参考音频
```

## 五、⚠️ 合规：这一节请认真看

**克隆声音这件事，法律风险不在技术，在「你用了谁的声音」。**

### 按风险从低到高

| 来源 | 能不能用 | 说明 |
|---|---|---|
| **自己的声音** | ✅ 随便用 | 没有任何限制，公开发布也行 |
| **明确授权的朋友** | ✅ | **留个书面/聊天记录**（对方说「可以」就行） |
| **CC-0 / 公有领域**（Common Voice） | ✅ | 最宽松，商用都行 |
| **Apache-2.0**（AISHELL-3） | ⚠️ | 见下面的坑 |
| **研究用途数据集**（KeSpeech / THCHS-30） | ⚠️ | 仅限学术，别公开发布 |
| **影视/配音演员/主播** | ❌ | 即使「网上能下到」也不行 |
| **公众人物、任何人未经同意** | ❌ | 违法，且**深度伪造**是加重情节 |

### ⚠️ AISHELL-3 的许可证有个坑

- OpenSLR 和 HuggingFace 上标的是 **Apache-2.0**（允许商用）
- 但 **ModelScope 页面上写的是**「支持学术研究，未经允许禁止商用」

**两个说法打架。** 我的建议：

- **自己在本地玩** → 没问题，放心用
- **要把游戏发给别人 / 发到网上** → 要么换成自录或 CC-0 音色，
  要么去 [aishelltech.com](http://www.aishelltech.com/aishell_3) 确认一下商用条款

### 一条实用原则

> **问自己一句：如果原声主人看到这个，他会不高兴吗？**
> 会 → 别用。这是最简单也最可靠的判断标准。

## 六、音频质量要求（放哪来的都一样）

| 项 | 要求 | 为什么 |
|---|---|---|
| **时长** | 6~10 秒 | 太短学不像，太长没必要 |
| **采样率** | ≥ 16000 Hz | CosyVoice 的 `load_wav` 硬性要求，低于这个直接报错 |
| **声道** | 单声道 | 立体声会让特征提取的形状不对 |
| **背景** | 无音乐、无噪音、无第二个人声 | 有噪音会一起被学进去 |
| **内容** | 一句自然的话，音节别太单一 | 「你好」这种学出来的嗓子会偏 |
| **⚠ 文本** | **必须同时提供准确转写** | 见下 |

### ⚠️⚠️ 最后这条最容易翻车 —— 有实测数据

CosyVoice 注册音色时要**同时**给音频和它的转写文本：

```python
model.add_zero_shot_spk(prompt_text, prompt_wav, spk_id)
```

**文本对不上（或干脆不给），克隆质量会明显崩。** 这不是理论推测，我实测过：

同一句「这把我加注。」（本该约 2 秒），换三份不同的参考音频：

| 参考音频 | 转写 | 输出时长 | 结果 |
|---|---|---|---|
| `音色参考/liyi.wav` | ✅ 有 | **1.80 秒** | 正常 |
| 仓库 `zero_shot_prompt.wav` | ✅ 有 | **1.32 秒** | 正常 |
| 仓库 `cross_lingual_prompt.wav` | ❌ **没给** | **4.80 秒** ⚠ | **又长又乱，还削波**（采样值冲到 -1.0138） |

**这三个样本就在工程目录里，双击就能听出差别：**

```
_试听-换音色对比-1_edge李姨.wav
_试听-换音色对比-2_仓库示例(有转写).wav
_试听-换音色对比-3_仓库示例(无转写).wav      ← 听这个，明显不对
```

**结论：转写文本不是可选项。** 6 个字的文本，输出被拉成 4.8 秒 —— 模型在没有对齐信息时，
把参考音频的内容和韵律一起混进来了。

所以：
- 从数据集挑 → 脚本自动带出转写（`.txt`）
- 自己录 → **必须自己手写一句**，写在 `音色参考\<key>.txt`
- 拿别人的音频 → 得先听写出内容

脚本已经处理好了：注册时**优先读 `<key>.txt`**，没有才回落到内置句。
用 `准备音色.py --list` 能一眼看到每个角色用的是哪段文本。

## 八、⚠ 换嗓子必踩的一个坑：「已注册，跳过」

**症状**：你换掉了 `音色参考/liyi.wav`，重跑 `准备音色.py`，它一路打印

```
   ⏭ liyi     已注册，跳过
   ...
   音色表已写入：...\spk2info.pt
```

—— 看着全对，**其实一个字都没写**（`spk2info.pt` 的修改时间一动不动），听出来还是老嗓子。

**根因**：脚本判断「音色名已存在」就跳过。但「名字存在」只说明**注册过**，
不代表注册的是**你现在这个参考音频**。换文件不会让它重新注册。

**解法**：加 `--rereg` 强制重来（这个参数就是踩了坑之后补上的）。

```
...\envs\cosyvoice\python.exe 配音服务\准备音色.py --rereg
```

修好之后它才真的会打印 `✅ liyi 已注册为音色「liyi」`，并且音色表体积会变
（实测换真人音色后 `spk2info.pt` 从 686 KB → 702 KB —— 这是**真的写盘了**的旁证）。

**怎么一眼判断有没有生效**：看 `spk2info.pt` 的修改时间。

```
dir "%COSY_REPO%\pretrained_models\CosyVoice2-0.5B\spk2info.pt"
```

> 教训和第十三轮那次是同一个：**「报告成功」和「真的写盘」是两件事，必须找一个独立旁证去验。**
