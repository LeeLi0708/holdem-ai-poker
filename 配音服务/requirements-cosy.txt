# CosyVoice 2 推理环境依赖（Windows / 已实测跑通）

# ⚠ 这不是上游 requirements.txt 的照抄。
#   上游那份是给 Linux + 训练用的，照抄会拖进 deepspeed / tensorrt / vllm / pynini
#   这些在 Windows 上装不动或根本用不到的东西。
#   这份是「**照着实测的 import 链一个一个查出来的**」，torch 2.3.1+cu121 上验证通过。
#
# 安装顺序很重要，见 安装CosyVoice环境.bat，或按下面四步手动：
#
#   ① pip install "setuptools<81"
#        新版 setuptools(≥81) 删了 pkg_resources，而 openai-whisper 的 setup.py 还在用它。
#
#   ② 装 torch / torchaudio 的 CUDA 版
#        pip install torch==2.3.1 torchaudio==2.3.1 --index-url https://download.pytorch.org/whl/cu121
#      ⚠ PyPI 上的是 CPU 版，必须走 pytorch 官方源。
#      ⚠ 单连接下载被限速到 1MB/s 以下（2.4GB 要半小时），
#        推荐用 并发下载.py 先拉下来再从本地装（实测 2.3GB / 83 秒）。
#
#   ③ pip install --no-build-isolation "openai-whisper==20231117"
#        ⚠ 必须带 --no-build-isolation。因为 pip 的**隔离构建环境**里用的是新版
#          setuptools，第①步的降级在那里不生效，会报 ModuleNotFoundError: pkg_resources。
#
#   ④ pip install -r requirements-cosy.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
#
# 注意：torch / torchaudio 不在下面的清单里（见步骤②）。
